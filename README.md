## Project Overview
This repository contains our Godot 2D game project for Lab 3.  
The main scene (`MainWorld.tscn`) includes instances of individual scenes contributed by each group member:

- **Anh:** Player movement, coin collection, and score logic  
- **Kareena:** Background visuals and UI design  
- **John:** Additional scene effects  

---

## Game Summary
The game allows players to move around the frame and earn points for every coin collected.  
When the player reaches 10 points, the game ends, and a winning message is displayed.
